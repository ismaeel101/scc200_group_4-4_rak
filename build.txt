OptiRoute — Build & Run Instructions

All steps run inside a Dev Container (Docker + VSCode Dev Containers extension required).
The lab machines have these installed by default.

═══════════════════════════════════════════════════════
STEP 1 — Open in Dev Container
═══════════════════════════════════════════════════════
1. Open the unzipped project folder in VSCode
2. VSCode will automatically prompt: "Reopen in Container" — click it
   (If not prompted: press Ctrl+Shift+P → type "Reopen in Container" → select it)
3. Wait for the container to fully build before continuing

═══════════════════════════════════════════════════════
STEP 2 — Verify databases are present
═══════════════════════════════════════════════════════
The following database files are included in the submission.
Verify they exist before continuing:

  /workspace/bus.db
  /workspace/rail.db
  /workspace/stops.db
  /workspace/backend/bus.db
  /workspace/backend/rail.db
  /workspace/backend/stops.db

═══════════════════════════════════════════════════════
STEP 3 — Install dependencies
═══════════════════════════════════════════════════════
Open a terminal inside the container and run:

  pip install uvicorn sqlalchemy fastapi requests httpx --break-system-packages

Then in the same terminal:

  cd /workspace/frontend && npm install

═══════════════════════════════════════════════════════
STEP 4 — Sync bus stops
═══════════════════════════════════════════════════════
Still in the same terminal:

  cd /workspace/backend && python3 sync_bus_stops.py

═══════════════════════════════════════════════════════
STEP 5 — Check port 8000 is free
═══════════════════════════════════════════════════════
If port 8000 is already in use, run:

  ss -tlnp | grep 8000
  kill -9 <PID>

(Replace <PID> with the number shown in the output)

═══════════════════════════════════════════════════════
STEP 6 — Start the backend (keep this terminal open)
═══════════════════════════════════════════════════════
  cd /workspace/backend
  PYTHONPATH=/workspace/backend python3 -m uvicorn app.api:app --reload --port 8000

Expected output: INFO: Application startup complete.

A popup will appear in the bottom-left of VSCode:
"Open in Browser" or "Port 8000 forwarded" — this confirms
the backend server is running and stops are being served.

═══════════════════════════════════════════════════════
STEP 7 — Start the frontend (open a NEW terminal)
═══════════════════════════════════════════════════════
Open a second terminal (+ button in the VSCode terminal panel)

  cd /workspace/frontend && npm run dev

Then open: http://localhost:5173

═══════════════════════════════════════════════════════
NOTE: No VPN or internet connection is required.
All data is self-contained within the submission databases.
Live data feeds will attempt to connect but the app will
automatically fall back to timetable data if unavailable.
